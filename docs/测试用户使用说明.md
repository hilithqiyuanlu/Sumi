# Sumi 测试用户使用说明

Sumi 是一个把日历、待办、项目和 AI 放在同一个首页的学习助手。第一次使用时，花两分钟了解下面几个操作就够了。

## 先做这一步：配置 AI

复制 `sk-c4c59d6d3212480ebc8846446275fcb9`，它相当于让 Sumi 能和你对话、生成计划的钥匙。

```
首页从左边缘向右滑 → 设置 → DeepSeek API Key → 粘贴 → 保存
```

保存后回到首页，就可以直接和 Sumi 聊天。

> `Tavily API Key`、本地智能和开发者选项都不是第一次使用的必填项，可以先不管。

如果需要联网搜索能力，让智能来源更可靠，可以去 tavily 官网 `https://tavily.com/`，免费申请一个类似上面的 API Key。


```
顶部日期条：看哪天、选哪天
        ↓ 拉开小短线
月历 + 项目 + 月度计划
        ↑ 往上推小短线
回到当天聊天和事项
```

### 1. 选日期

- 横向滑动顶部的日期条，停下后中间日期会被选中。
- 也可以直接点某一天。
- 带小点的日期，表示这天还有未完成事项。

### 2. 展开月历和项目

日期条下方有一条短横线。**向下拉或点它**，可以展开当月月历、项目和月度计划；**向上推**可收起。

项目在月历下方横向排列：

- 点项目：切换查看这个项目的月度计划。
- 点“新建项目”：按页面引导填写并生成计划。
- 长按已建项目：可以删除项目，以及它对应的月卡和系统事项。

## 待办怎么用

当天待办显示为一排横向卡片，不是传统的纵向清单。

```
点事项卡 → 编辑标题、备注、日期、项目或删除
长按事项卡 → 拖到顶部某个日期 → 改到那一天
点圆圈 → 标记完成 / 再点一次恢复未完成
```

不要担心把事项拖到过去：Sumi 会阻止这种操作。

## 怎么和 Sumi 说

在底部输入框直接说人话即可。Sumi 可以回答问题，也能在开启相应工具后帮你操作。

| 你可以这样说 | Sumi 会做什么 |
| --- | --- |
| `帮我安排今天先做什么` | 结合当天事项给建议 |
| `下午 3 点提醒我背单词` | 创建闹钟卡片 |
| `我现在学习英语 30 分钟` | 创建学习计时器 |
| `我想学 Python，每周 5 小时，学 3 个月` | 追问缺少信息，再进入项目生成 |
| `帮我记住我晚上更适合学习` | 记录为你的偏好 |

### 计时器和闹钟

- Sumi 创建后会在聊天里显示卡片。
- 计时器：点开始、暂停或完成；完成后会显示本次实际学习时长。
- 闹钟：到点会用系统声音和震动提醒。
- 需要“立刻开始”时，直接说：`现在开始计时 30 分钟`。

### 语音输入

按住输入框附近开始说话，松开即可发送；上滑后松开会取消。本功能需要允许麦克风权限。

## 两个常用入口

从**左边缘向右滑**可打开侧边栏：

- **记忆**：查看或调整 Sumi 记住的长期偏好和学习信息。
- **工具**：开关“搜索资料、读取事项、计时与闹钟、对话新建项目”等能力。工具关闭后，Sumi 不会使用它。
- **设置**：配置 API Key、修改思考模式等。

## 容易搞错的操作

| 看到的情况 | 应该怎么做 |
| --- | --- |
| 发消息后没有回复 | 先确认“设置”里已保存 DeepSeek API Key，并检查网络 |
| 想删除一段刚发的对话 | 长按**自己发出的最新一条消息**，选择编辑或删除本轮对话 |
| 想修改更早的消息 | 当前只支持编辑最新一条自己发出的消息；可重新发一条补充 |
| 看到“安排较满” | 可点“获取建议”查看哪些事项可调整；不想处理就点“忽略本次” |
